# Full Bash correctness runner

Historical default and benchmark-option cold/warm results are in [the consolidated study](../evaluation-checkpoint-2026-10-16/README.md). The qualified implementation passed all 83 Bash 5.2.37 default groups and all 82 Bash 5.1.16 benchmark-option groups, including regression policies and scratch cleanup. Existing normalization is implemented in the harness; this does not claim every raw driver exit status is identical.

Build Incr and sibling Observe first. Installed Bash 5.2.37 with official test corpus/helpers is under `qualification/.tools/bash-5.2.37`; Node and Python prerequisites live under `.tools` and `.venv`. To recreate the Bash installation/parser environment explicitly, run `python3 studies/bash-parity-audit-2026-10-08/harness/setup.py`. For a second version pass `--corpus-provenance corpus-provenance-5.1.16.json` and a separate `--bash-build` path. Setup defaults to checksum-verified corpus provenance and never launches tests.

Inspect `bash studies/bash-parity-audit-2026-10-08/run.sh --help`, then choose a fresh explicit output directory under this study's ignored `results/`. Native and Incr executions are cold/warm with source/binary snapshots, bounded processes and recorded diffs. `harness/test_compare.py` and `harness/test_terminal.py` exercise comparison/supervision. Do not run concurrently with benchmarks. No runs or monitor timers are scheduled.
